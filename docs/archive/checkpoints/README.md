# Hồ sơ theo mốc

Thư mục này lưu bản đầy đủ của các báo cáo kiểm chứng, runbook cutover và tài liệu migration cũ từng đặt ở gốc `docs/`. Nội dung ghi trạng thái tại thời điểm soạn, không phải cấu hình hay kết quả runtime tự cập nhật. Các tham chiếu từ Backbone đã được cập nhật tới vị trí này.

| Chủ đề | Hồ sơ |
| --- | --- |
| CDC order/catalog/offer và retirement | `CDC11_*`, `CDC12_*`, `CDC13_*`, `CDC14_*` |
| Swarm candidate, live, autoscale | `SWARM_*`, `KLTN_VPS_*` |
| Phạm vi và vận hành trước tái tổ chức | `FEATURE_STATUS.md`, `MONITORING.md`, `REPOSITORY_LAYOUT.md`, `SWARM_MIGRATION.md`, `TESTING.md` |
| Tài khoản và bảo mật theo mốc | `ACCOUNT_SECURITY_2026-09-09.md` |
| Inventory phục vụ CDC-14 | `CDC14_VPS_RESOURCE_INVENTORY_2026-10-31.json` |

Tài liệu sử dụng hiện tại: [mục lục hệ thống](../../current/README.md).
