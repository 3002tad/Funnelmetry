# CDC inventory kit at one location — 2026-10-30

**Result:** `PASS_SAMPLE_ONLY` on the isolated combined clone. This extends the earlier one-item/multi-location evidence with one new Medusa kit shape. It does not activate an inventory analytical asset or change Medusa/Pipeline live.

The existing `funnelmetry_cdc_combined_shadow_c1` project was restarted with its preserved volumes and offsets. `probe-combined-cdc-kit.py` selected a published variant with one managed inventory item and one eligible stock location. In one clone-only transaction it added a second inventory item, a `product_variant_inventory_item` link with `required_quantity=2`, and an inventory level with stocked/raw quantity 5 and reserved quantity 0. The independent Medusa Store API reported available variant quantity **2**. The stage-2 governed CDC projection reconciled all 16 allowlisted tables and contained the new link; the stage-1 governed catalog projection supplied the product and variant flags. The CDC resolver also returned **2** with reason `inventory_kit_single_location_conformed`. All fixture rows were removed in `finally`, projections reconciled again, and Store API returned exactly to its pre-test response (`RESTORED`).

The resolver now accepts only this conformed multi-item/one-location shape, using the minimum of `floor((stocked-reserved)/required_quantity)` across the variant's items. It rejects duplicate links, missing levels, unverified backorders and multi-location kits. One-item/multi-location behavior remains as previously tested. This follows Medusa's [inventory-kit](https://docs.medusajs.com/resources/commerce-modules/inventory/inventory-kit) and [reservation](https://docs.medusajs.com/resources/commerce-modules/inventory/reservations-lifecycle) descriptions, but the observed runtime result covers **one** controlled variant with no reservation on the new item. It does not establish general `available_to_sell` semantics, checkout reservation behavior for kits, backorder policy, stock across multiple locations, price-list/rule/tier selection or a production quality SLO.
